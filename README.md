# 🏁 F1 Pit Wall OS - Race Strategy Decision Support System

## 📌 Overview
F1 Pit Wall OS is a professional-grade decision-support software designed for Formula 1 race strategy. It moves beyond simple lap-time calculators by integrating **Dynamic Programming optimization**, **Telemetry-based tyre degradation modeling (Machine Learning via SciPy)**, and **Stochastic Monte Carlo simulations**.

This tool is designed to replicate the analytical workflow of an F1 Strategy Engineer, providing mathematically optimal pit-stop windows, risk assessment, and backtesting capabilities against real-world historical data.

## 🚀 Key Features
*   **Dynamic Programming Optimizer:** Calculates the absolute optimal race strategy (stops and compounds) in O(K * N^2) time complexity, integrating fuel burn effect and tyre warm-up penalties.
*   **Real Telemetry Integration:** Connects to FIA timing data via FastF1. Automatically extracts real lap times and fits mathematically accurate degradation curves (Linear, Quadratic, Exponential) using SciPy.
*   **Monte Carlo Risk Matrix:** Runs thousands of simulated races injecting real-world chaos (lap time variance, 5% probability of botched pit stops) to evaluate strategy robustness.
*   **Backtesting Engine:** Compares the mathematically optimal strategy generated by the OS against the *actual* strategy executed by an F1 team during a historical race.
*   **Automated Pre-Race Brief:** Generates a professional, downloadable PDF report containing the selected optimal strategy and pace projection graph.

## 🏗️ Software Architecture
The application is fully modularized for maintainability and scalability:
*   `app.py`: The main Streamlit dashboard and UI router.
*   `optimization.py`: The mathematical core (DP algorithms, Monte Carlo engine, Fuel & Warm-up physics).
*   `telemetry.py`: Data extraction and curve fitting (FastF1 API, SciPy ML models).
*   `report.py`: Automated PDF report generator (`fpdf2`).

## ⚙️ Installation & Usage (Local)

1. Clone the repository.
2. Install the dependencies:
```bash
pip install -r requirements.txt
```
3. Run the Streamlit application:
```bash
streamlit run app.py
```

## ⚠️ Model Limitations
As an engineering tool, this model relies on "clean air" mathematics. Current limitations include:
*   **Dirty Air / Traffic:** The model does not dynamically penalize pit exits into heavy traffic.
*   **Track Temperature:** Degradation curves are fitted on average session data and do not adapt dynamically to sunset/temperature drops.
*   **Tyre Saving:** Assumes the driver pushes to the maximum potential of the tyre model, whereas real drivers manage thermal degradation.
